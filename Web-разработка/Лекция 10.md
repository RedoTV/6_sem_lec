## Events

### Mouse Events:
- mouseenter - курсор мыши перемещается на элемент, к которому прикреплен слушатель событий, не всплывает
- mouseover - курсор мыши перемещается на элемент, к которому прикреплен слушатель события или на 1 из его дочерних элементов

События Focus и Blur не всплывают вверх по иерархии DOM. 

Обработка событий

Существует 3 способа регистрации событий:
1. встроенная HTML атрибутами.
2. традиционная модель DOM - используя свойства DOM элементов
3. W3C модель DOM - используя обработчики события DOM 

примеры:

```js
//встроенная HTML аттрибутами
<button onclick="alert('Clicked!')">Click me</button>
//традиционная модель DOM
<button id="myButton">Click me</button>
<script>
  const button = document.getElementById('myButton');
  button.onclick = function() {
    alert('Clicked!');
  };
</script>
//W3C модель DOM
<button id="myButton">Click me</button>
<script>
  const button = document.getElementById('myButton');
  button.addEventListener('click', function() {
    alert('Clicked!');
  });
</script>
```

синтаксис для addEventListener: 
```js
element.addEventListener(event, eventHandler, captureEvent);
var button = document.getElementById('myButton');

button.addEventListener('click', function() {
  alert('Clicked!');
}, false);
```

метод removeEventListener удаляет обработчика события и требует передать именно ту функцию-обработчик, которая была назначена. Если функцию не сохранить где-либо, а просто передать addEventListener, то потом получить ее обратно, чтобы снять обработчик будет невозможно. Нет метода, который позволяет считать обработчики событий, назначенные через addEventListener. 

Синтаксис:
```js
element.removeEventListener(event, eventHandler, captureEvent);
var button = document.getElementById('myButton');
function handleClick() {
  alert('Clicked!');
}
button.addEventListener('click', handleClick, false);
// Позже, если нужно удалить обработчик:
button.removeEventListener('click', handleClick, false);
```

объект event содержит информацию о типе события, цели события клавиши клавиатуры которая была нажата при запуске события клавиатуры, о кнопке мыши которая была нажата при запуске события мыши и о положении мыши на экране.

### Event chain

Существует 2 типа цепочек событий:
- всплытие (bubbling) - всплывающие обработчики всплывают вверх по цепочке при наступлении события обработчики сначала срабатывают на самом вложенном элементе, затем на его родителе, затем на родителе родителя и так далее вверх по цепочке вложенности. Всплывают почти все события.
- перехватывание (capturing) - перехватывающие обработчики идут вниз цепочки. Первый исполняемый обработчик выполняется на самом внешнем родителе (если он задан). Последний исполняемый обработчик выполняется на самом целевом объекте.

Стандарт W3C позволяет программисту самому задавать поведение событий на странице, используя третий параметр метода addEventListener. Если он равен true, то событие будет перехватывающим, если false - всплывающим. Т.е. при клике сначала будут происходить фаза спуска и будут вызываться события, привязанные с флагом `captureEvent = true` (фаза перехвата событий). Затем будет запущена фаза подъема, и остальные события будут выдаваться в порядке по DOM-дереву (фаза всплытия событий). по умолчанию события всегда подписываются на фазу всплытия, т.е. `captureEvent = false`. 

Любой промежуточный обработчик может решить, что событие полностью обработано и чтобы остановить (перехват) используется метод `stopPropagation`, который останавливает дальнейшее распространение события по цепочке.  

Свойства events:
- target - целевой объект (на нем нажали)
- currentTarget - целевой объект события обрабатываемого в данное время (всплытие или перехват)
- bubbles - логическое значение, указывающее является ли событие всплывающим.
- eventPhase - какая фаза события в настоящее время проверяется (1 - перехват, 2 - целевой объект, 3 - всплытие)
- type - имя события без учёта регистра 

Методы events:
- preventDefault() - отменяет событие, если оно является отменяемым, без остановки дальнейшего распространения события. 
- stopPropagation() - если у элемента есть несколько обработчиков, то даже при прекращении вспылтия все они будут выполнены. Т.е. stopPropagation() препятствует продвижению события дальше, но на текущем элементе все обработчики отработают. 

```js
var theParent = document.querySelector('#theDude');
theParent.addEventListener('click', doSomeSomething, false);

function doSomeSomething(e) {
  if (e.target.id === 'theDude') {
    console.log('The Dude clicked');
  }
  e.stopPropagation();
}
```

Для создания пользовательских событий используется конструктор `CustomEvent`. 

Создадим событие тройного клика мышкой:
```js
var event = new CustomEvent('tripleclick', {
  detail: {
    message: 'Тройной клик мышкой',
    time: new Date(),
  },
});
``` 

```js

body.dispatchEvent(event);
``` 

для запуска своего события используем метод `dispatchEvent` на элементе, который должен быть целью события.

```js
(function(){
  var button = document.getElementById('btn-click');
  var counter = 0;
  button.addEventListener('click', function() {
    counter++;
    if (counter === 3) {
      body.dispatchEvent(event);
    }
  }, false)
}();
```

js имеет очередь событий - это список событий, которые должны быть обработаны. 

Вызов setTimeout добавит событие в очередь по прошествии времени, указанного во втором аргументе, если очередь событий на этот момент будет пуста, то событие будет обработано сразу же в противном случае событию setTimeout придется ожидать завершения обработки остальных событий, которые были добавлены в очередь до него. Именно поэтому второй паметр setTimeout корректно считает не временем, через которое выполниться функция из первого аргумента а минимальным временем, через которое она сможет выполниться.

setInterval в отличие от setTimeout запускает выполнение функции не один раз, а регулярно повторяя ее через указанный интервал. Они могут обмениваться данными, например, с помощью глобальных переменных. они не имеют доступа к dom элементам, поэтому они используются при вычислениях, для загрузки нескольких ядеро или процессов одновременно.
