Лекция 8

React - JS библиотека с открытым исходным кодом для разработки UI. React был создан Jordan Walke, инженером Facebook. Исходный код React был опубликован в мае 2013 года.

React разработка заключается в описании того, что нужно вывести на страницу. 

В React используется синтаксис JSX, который позволяет писать HTML-подобный код внутри JavaScript. JSX компилируется в обычный JavaScript, который может быть выполнен браузером. Обычно JSX используется для описания структуры компонентов и их разметки, прежде чем запускать JSX код в браузере его нужно преобразовать в js код для этого можно использовать либо пакет webpack, указать комилятор например babel. JSX гораздо проще понимать и писать чем js код. Компоненты в React - это повторяющиеся части кода, кооторые изменяются в зависимости от контекста. Каждый компонент зависит от от своего состояния. React делает код более понятным и структурированным, дает возможность повторно использовать большие блоки кода. React эффективен в проектах с большим числом динамеских страниц.

Доступ к React можно получить 2-умя способами:
1. использовать онлайн редакторы кода CodePen, Codesandbox или скачать html файл с шаблоном с github. После этого свой код можно онлайн прогонять через babel
2. установить React на компьютер, для этого нужно установить Node.js с сайта nodejs.org:
   - а. create-react-app с помощью npm: `npm i -g create-react-app` (пишем в командной строке nodejs)
   - б. после установки пакета создаем шаблон приложения `create-react-app my-first-app` (my-first-app - название папки, в которой будет создано приложение). После успешной установки Node js выводит сообщение "Happy hacking"
   - в. `cd my-first-app` -> `npm start`. В результате выводится вращающийся логотип React. 

### Веб версия игры в крестики нолики. 

Весь код за исключением стилей будем писать в файле App.js (в папке src). Сначала импортируем модуль React, веб-хук `useState` из него:

`import React, { useState } from "react";`

И библиотеку react-dom для рендеринга компонентов:

`import ReactDOM from "react-dom";`

рендеринг в React - это вычисление того что должно быть отображено на странице. Логику игры будем писать в компоненте App, который уже содержит код. Нужно оставить последнюю строку `export default App;`

С помощью `useState` создадим хук, который возвращает массив squares, в нем будем хранить клетки игрового поля. (Слайд 7). 

squares будет инициализироваться в начале игры, как массив из 9 пустых элементов, а его состояние при необходимости будет изменять функция setSquares. 

Хуки - это нововведение в React 16.8, которое позволяет определять и использовать состояние и другие возможности React без написания классов. По сути хуки - это функции, которые позволяют "подцепиться" к состоянию и другим возможностям React. Можно создавать свои хуки, в React есть встроенные хуки, например useState, который служит для управления состоянием. 

Создадим второй хук для хранения очередности хода `const [xIsNext, setXIsNext] = useState(true);`. По умолчанию состояние устанавливается в true, что означает, что первым ходит игрок X. Функция setXIsNext переключает очереди игроков. На каждом ходе будем проверять, не определился ли победитель (функция calculateWinner).

В функцию передаётся массив squares с текущими значениями клеток игрового поля. В массиве lines содержаться выигрышные комбинации полей. Функция перебирает их подставляя на место индекса входного массива, и если все 3 значения совпадут, возвращает победителя (который может быть X или O) или null, если победитель не определился. 

```js
const calculateWinner = (squares) => {
  const lines = [
    [0, 1, 2],
    [3, 4, 5],
    [6, 7, 8],
    [0, 3, 6],
    [1, 4, 7],
    [2, 5, 8],
    [0, 4, 8],
    [2, 4, 6],
  ];

  for (let i = 0; i < lines.length; i++) {
    const [a, b, c] = lines[i];
    if (squares[a] && squares[a] === squares[b] && squares[a] === squares[c]) {
      return squares[a];
    }
  }
  return null;
};
```

Слайд 9

Значение calculateWinner храниться в переменной winner. Настроим взаимодействие игроков с интерфейсом. Оно будет происходить через функцию handleClick, которая вызывается при клике на клетку игрового поля. Она создает копию массива squares, проверяет может ли текущий игрок сделать ход в выбранный square, и изменяет массив squaresCopy и состояние игрока (чередуя игроков) если ход был возможен.

```js
function App() {
  const [squares, setSquares] = useState(Array(9).fill(null));
  const [xIsNext, setXIsNext] = useState(true);
  const winner = calculateWinner(squares);
  // ...

  const handleClick = (i) => {
    const squaresCopy = [...squares];
    if (calculateWinner(squaresCopy) || squaresCopy[i]) {
      return;
    }
    squaresCopy[i] = xIsNext ? "X" : "O";
    setSquares(squaresCopy);
    setXIsNext(!xIsNext);
  };
}
```
