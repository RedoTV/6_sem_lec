# Java/XML: Обработка событий (OnClickListener, OnTouchListener, TextWatcher, OnEditorActionListener)

## OnClickListener — обработка кликов

### Способ 1: Через лямбду (самый короткий)

```java
Button button = findViewById(R.id.button);
button.setOnClickListener(v -> {
    Toast.makeText(this, "Клик!", Toast.LENGTH_SHORT).show();
});
```

### Способ 2: Через реализацию интерфейса в Activity

```java
public class MainActivity extends AppCompatActivity implements View.OnClickListener {

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        Button button1 = findViewById(R.id.button1);
        Button button2 = findViewById(R.id.button2);

        button1.setOnClickListener(this);
        button2.setOnClickListener(this);
    }

    @Override
    public void onClick(View v) {
        int id = v.getId();
        if (id == R.id.button1) {
            Toast.makeText(this, "Кнопка 1", Toast.LENGTH_SHORT).show();
        } else if (id == R.id.button2) {
            Toast.makeText(this, "Кнопка 2", Toast.LENGTH_SHORT).show();
        }
    }
}
```

### Способ 3: Через XML (android:onClick)

```xml
<Button
    android:id="@+id/button"
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:onClick="onButtonClick"
    android:text="Нажми" />
```

```java
public void onButtonClick(View view) {
    Toast.makeText(this, "Клик через XML!", Toast.LENGTH_SHORT).show();
}
```

### Способ 4: Анонимный класс

```java

    @Override
```

## OnTouchListener — обработка касаний

```java
button.setOnTouchListener((v, event) -> {
    float x = event.getX();
    float y = event.getY();

    switch (event.getAction()) {
        case MotionEvent.ACTION_DOWN:
            Log.d("TAG", "Касание началось: x=" + x + ", y=" + y);
            break;
        case MotionEvent.ACTION_MOVE:
            Log.d("TAG", "Движение: x=" + x + ", y=" + y);
            break;
        case MotionEvent.ACTION_UP:
            Log.d("TAG", "Касание закончилось");
            break;
    }
    return false; // false = другие слушатели тоже получат событие
});
```

### Типы действий MotionEvent

| Константа | Описание |
|-----------|----------|
| `ACTION_DOWN` | Палец коснулся экрана |
| `ACTION_MOVE` | Палец движется |
| `ACTION_UP` | Палец отпущен |
| `ACTION_CANCEL` | Событие отменено |

### GestureDetector — распознавание жестов

```java
GestureDetector gestureDetector = new GestureDetector(this, new GestureDetector.SimpleOnGestureListener() {
    @Override
    public boolean onSingleTapUp(MotionEvent e) {
        Toast.makeText(MainActivity.this, "Одиночный тап", Toast.LENGTH_SHORT).show();
        return true;
    }

    @Override
    public boolean onDoubleTap(MotionEvent e) {
        Toast.makeText(MainActivity.this, "Двойной тап", Toast.LENGTH_SHORT).show();
        return true;
    }

    @Override
    public void onLongPress(MotionEvent e) {
        Toast.makeText(MainActivity.this, "Длинное нажатие", Toast.LENGTH_SHORT).show();
    }

    @Override
    public boolean onFling(MotionEvent e1, MotionEvent e2, float velocityX, float velocityY) {
        if (e1.getX() - e2.getX() > 100) {
            Toast.makeText(MainActivity.this, "Свайп влево", Toast.LENGTH_SHORT).show();
        } else if (e2.getX() - e1.getX() > 100) {
            Toast.makeText(MainActivity.this, "Свайп вправо", Toast.LENGTH_SHORT).show();
        }
        return true;
    }

    @Override
    public boolean onScroll(MotionEvent e1, MotionEvent e2, float distanceX, float distanceY) {
        // Прокрутка
        return true;
    }
});

view.setOnTouchListener((v, event) -> {
    gestureDetector.onTouchEvent(event);
    return true;
});
```

## TextWatcher — отслеживание ввода текста

```java
EditText editText = findViewById(R.id.editText);
editText.addTextChangedListener(new TextWatcher() {
    @Override
    public void beforeTextChanged(CharSequence s, int start, int count, int after) {
        // До изменения: s — текущий текст, start — позиция начала изменения
        Log.d("TAG", "before: " + s);
    }

    @Override
    public void onTextChanged(CharSequence s, int start, int before, int count) {
        // Во время изменения: s — новый текст
        Log.d("TAG", "onText: " + s);
        textView.setText(s);
    }

    @Override
    public void afterTextChanged(Editable s) {
        // После изменения: s — итоговый текст
        Log.d("TAG", "after: " + s);
        // Валидация
        if (s.length() > 20) {
            editText.setError("Максимум 20 символов");
        }
    }
});
```

### Пример: поиск по мере ввода

```java
editText.addTextChangedListener(new TextWatcher() {
    @Override
    public void beforeTextChanged(CharSequence s, int start, int count, int after) {}

    @Override
    public void onTextChanged(CharSequence s, int start, int before, int count) {
        filterList(s.toString());
    }

    @Override
    public void afterTextChanged(Editable s) {}
});

private void filterList(String query) {
    List<String> filtered = new ArrayList<>();
    for (String item : allItems) {
        if (item.toLowerCase().contains(query.toLowerCase())) {
            filtered.add(item);
        }
    }
    adapter.updateList(filtered);
}
```

## OnEditorActionListener — обработка кнопки на клавиатуре

```java
editText.setOnEditorActionListener((v, actionId, event) -> {
    if (actionId == EditorInfo.IME_ACTION_DONE) {
        String text = editText.getText().toString();
        Toast.makeText(this, "Введено: " + text, Toast.LENGTH_SHORT).show();

        // Скрыть клавиатуру
        InputMethodManager imm = (InputMethodManager) getSystemService(INPUT_METHOD_SERVICE);
        imm.hideSoftInputFromWindow(editText.getWindowToken(), 0);

        return true;
    }
    return false;
});
```

### Типы IME Action (в XML)

```xml
<EditText
    android:imeOptions="actionDone"      <!-- Галочка -->
    android:imeOptions="actionGo"        <!-- Кнопка "Перейти" -->
    android:imeOptions="actionSearch"    <!-- Иконка поиска -->
    android:imeOptions="actionSend"      <!-- Кнопка "Отправить" -->
    android:imeOptions="actionNext"      <!-- Стрелка "Далее" -->
    android:imeOptions="actionNone"      <!-- Без кнопки -->
    android:singleLine="true" />         <!-- Обязательно для imeOptions -->
```

Соответствие в Java:
```java
EditorInfo.IME_ACTION_DONE
EditorInfo.IME_ACTION_GO
EditorInfo.IME_ACTION_SEARCH
EditorInfo.IME_ACTION_SEND
EditorInfo.IME_ACTION_NEXT
```

## OnCheckedChangeListener — Switch / CheckBox / RadioButton

### Switch

```java
Switch switchView = findViewById(R.id.switchView);
switchView.setOnCheckedChangeListener((buttonView, isChecked) -> {
```

## AdapterView.OnItemClickListener — ListView / Spinner

### ListView

```java
ListView listView = findViewById(R.id.listView);
ArrayAdapter<String> adapter = new ArrayAdapter<>(this,
    android.R.layout.simple_list_item_1, items);
listView.setAdapter(adapter);

listView.setOnItemClickListener((parent, view, position, id) -> {
    String item = (String) parent.getItemAtPosition(position);
    Toast.makeText(this, item, Toast.LENGTH_SHORT).show();
});

// Длинное нажатие
listView.setOnItemLongClickListener((parent, view, position, id) -> {
    Toast.makeText(this, "Длинное: " + items.get(position), Toast.LENGTH_SHORT).show();
    return true;
});
```

### Spinner

```java
Spinner spinner = findViewById(R.id.spinner);
ArrayAdapter<String> adapter = new ArrayAdapter<>(this,
    android.R.layout.simple_spinner_item, items);
adapter.setDropDownViewResource(android.R.layout.simple_spinner_dropdown_item);
spinner.setAdapter(adapter);

spinner.setOnItemSelectedListener(new AdapterView.OnItemSelectedListener() {
    @Override
    public void onItemSelected(AdapterView<?> parent, View view, int position, long id) {
        String item = (String) parent.getItemAtPosition(position);
        Toast.makeText(MainActivity.this, item, Toast.LENGTH_SHORT).show();
    }

    @Override
    public void onNothingSelected(AdapterView<?> parent) {
    }
});
```

## Важные моменты

- **OnClickListener** — самый частый слушатель, 4 способа подключения
- **TextWatcher** — три метода: `beforeTextChanged`, `onTextChanged`, `afterTextChanged`
- **OnEditorActionListener** — обработка кнопок клавиатуры (Done, Search, Next...)
- **OnTouchListener** — низкоуровневая обработка касаний (MotionEvent)
- `GestureDetector` — для распознавания жестов (тап, двойной тап, свайп, флинг)
- Лямбды (Java 8) — самый короткий способ: `view.setOnClickListener(v -> { })`
- `return true` в слушателях означает «событие обработано, не передавать дальше»
