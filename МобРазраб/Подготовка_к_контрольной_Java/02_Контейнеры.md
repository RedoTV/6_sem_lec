# Java/XML: Контейнеры (LinearLayout, RelativeLayout, ConstraintLayout, FrameLayout)

## LinearLayout

Располагает дочерние элементы **по горизонтали или вертикали**.

```xml
<LinearLayout
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:orientation="vertical"
    android:gravity="center"
    android:padding="16dp">

    <TextView
        android:layout_width="match_parent"
        android:layout_height="wrap_content"
        android:text="Первый" />

    <TextView
        android:layout_width="match_parent"
        android:layout_height="wrap_content"
        android:text="Второй" />

</LinearLayout>
```

### Параметры

| Параметр | Описание |
|----------|----------|
| `android:orientation` | `vertical` или `horizontal` |
| `android:gravity` | Выравнивание содержимого внутри |
| `android:layout_gravity` | Выравнивание самого элемента в родителе |
| `android:layout_weight` | Распределение свободного пространства |
| `android:weightSum` | Сумма весов (для контроля) |

### weight — распределение пространства

```xml
<LinearLayout
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:orientation="horizontal"
    android:weightSum="3">

    <Button
        android:layout_width="0dp"
        android:layout_height="wrap_content"
        android:layout_weight="1"
        android:text="A" />

    <Button
        android:layout_width="0dp"
        android:layout_height="wrap_content"
        android:layout_weight="2"
        android:text="B" />

</LinearLayout>
<!-- A займёт 1/3, B — 2/3 ширины -->
```

### gravity vs layout_gravity

```xml
<!-- gravity — выравнивание содержимого ВНУТРИ элемента -->
<LinearLayout android:gravity="center"> ... </LinearLayout>

<!-- layout_gravity — выравнивание САМОГО элемента в родителе -->
<TextView android:layout_gravity="end" />
```

Значения gravity: `top`, `bottom`, `left`, `right`, `center`, `center_vertical`, `center_horizontal`, `start`, `end`, `clip_vertical`, `clip_horizontal`. Можно комбинировать через `|`.

## RelativeLayout

Позиционирование элементов **относительно друг друга** или границ родителя.

```xml
<RelativeLayout
    android:layout_width="match_parent"
    android:layout_height="match_parent">

    <TextView
        android:id="@+id/title"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:layout_alignParentTop="true"
        android:layout_centerHorizontal="true"
        android:text="Заголовок" />

    <TextView
        android:id="@+id/subtitle"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:layout_below="@id/title"
        android:layout_centerHorizontal="true"
        android:text="Подзаголовок" />

    <Button
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:layout_alignParentBottom="true"
        android:layout_alignParentEnd="true"
        android:text="OK" />

</RelativeLayout>
```

### Позиционирование относительно родителя

| Атрибут | Описание |
|---------|----------|
| `layout_alignParentTop` | Прижать к верху |
| `layout_alignParentBottom` | Прижать к низу |
| `layout_alignParentStart` | Прижать к левому краю |
| `layout_alignParentEnd` | Прижать к правому краю |
| `layout_centerHorizontal` | Центрировать горизонтально |
| `layout_centerVertical` | Центрировать вертикально |
| `layout_centerInParent` | Центрировать полностью |

### Позиционирование относительно других элементов

| Атрибут | Описание |
|---------|----------|
| `layout_above` | Над указанным элементом |
| `layout_below` | Под указанным элементом |
| `layout_toStartOf` | Левее указанного элемента |
| `layout_toEndOf` | Правее указанного элемента |
| `layout_alignTop` | Выровнять верхнюю границу |
| `layout_alignBottom` | Выровнять нижнюю границу |
| `layout_alignStart` | Выровнять левую границу |
| `layout_alignEnd` | Выровнять правую границу |

## ConstraintLayout

Самый мощный контейнер. Позиционирование через **ограничения (constraints)** к другим элементам или границам родителя. Рекомендуемый контейнер.

```xml
<androidx.constraintlayout.widget.ConstraintLayout
    android:layout_width="match_parent"
    android:layout_height="match_parent">

    <TextView
        android:id="@+id/title"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="Заголовок"
        app:layout_constraintTop_toTopOf="parent"
        app:layout_constraintStart_toStartOf="parent"
        app:layout_constraintEnd_toEndOf="parent" />

    <TextView
        android:id="@+id/description"
        android:layout_width="0dp"
        android:layout_height="wrap_content"
        android:text="Описание"
        app:layout_constraintTop_toBottomOf="@id/title"
        app:layout_constraintStart_toStartOf="parent"
        app:layout_constraintEnd_toEndOf="parent"
        android:layout_marginStart="16dp"
        android:layout_marginEnd="16dp" />

    <Button
        android:id="@+id/button"
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="OK"
        app:layout_constraintBottom_toBottomOf="parent"
        app:layout_constraintEnd_toEndOf="parent"
        android:layout_marginEnd="16dp"
        android:layout_marginBottom="16dp" />

</androidx.constraintlayout.widget.ConstraintLayout>
```

### Принцип ограничений

Каждая сторона элемента должна быть привязана:
- К стороне другого элемента: `app:layout_constraintStart_toEndOf="@id/otherView"`
- К стороне родителя: `app:layout_constraintTop_toTopOf="parent"`

Если заданы ограничения с обеих сторон (start + end) и `layout_width="0dp"`, элемент растянется между ними.

### Центрирование

```xml
<!-- Центрирование горизонтально -->
app:layout_constraintStart_toStartOf="parent"
app:layout_constraintEnd_toEndOf="parent"

<!-- Центрирование вертикально -->
app:layout_constraintTop_toTopOf="parent"
app:layout_constraintBottom_toBottomOf="parent"

<!-- Центрирование полностью -->
app:layout_constraintStart_toStartOf="parent"
app:layout_constraintEnd_toEndOf="parent"
app:layout_constraintTop_toTopOf="parent"
app:layout_constraintBottom_toBottomOf="parent"
```

### Bias (смещение)

```xml
<!-- Сместить на 30% от левого края (по умолчанию 0.5 = центр) -->
app:layout_constraintHorizontal_bias="0.3"

<!-- Сместить на 70% от верха -->
app:layout_constraintVertical_bias="0.7"
```

### Chains (цепочки)

Распределение нескольких элементов по горизонтали или вертикали.

```xml
<!-- Chain style на первом элементе цепочки -->
app:layout_constraintHorizontal_chainStyle="spread"         <!-- Равномерно (по умолчанию) -->
app:layout_constraintHorizontal_chainStyle="spread_inside"  <!-- По краям -->
app:layout_constraintHorizontal_chainStyle="packed"          <!-- Сгруппированы в центре -->
```

### Guidelines

Невидимые направляющие линии для позиционирования.

```xml
<androidx.constraintlayout.widget.Guideline
    android:id="@+id/guideline"
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:orientation="vertical"
    app:layout_constraintGuide_percent="0.5" />

<!-- Использование -->
app:layout_constraintStart_toEndOf="@id/guideline"
```

### Barrier

Невидимый барьер по самому крайнему элементу.

```xml
<androidx.constraintlayout.widget.Barrier
    android:id="@+id/barrier"
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    app:barrierDirection="end"
    app:constraint_referenced_ids="textView1,textView2" />
```

## FrameLayout

Простейший контейнер. Располагает элементы **один поверх другого** (stack). Все дочерние элементы привязаны к левому верхнему углу.

```xml
<FrameLayout
    android:layout_width="match_parent"
    android:layout_height="200dp">

    <ImageView
        android:layout_width="match_parent"
        android:layout_height="match_parent"
        android:src="@drawable/background"
        android:scaleType="centerCrop" />

    <TextView
        android:layout_width="wrap_content"
        android:layout_height="wrap_content"
        android:text="Подпись"
        android:layout_gravity="bottom|end"
        android:textColor="#FFFFFF"
        android:padding="8dp" />

</FrameLayout>
```

Используется для:
- Наложения элементов друг на друга
- Фрагментов (контейнер для Fragment)
- Простых экранов с одним дочерним элементом

## ScrollView / NestedScrollView

Прокрутка содержимого.

```xml
<ScrollView
    android:layout_width="match_parent"
    android:layout_height="match_parent">

    <LinearLayout
        android:layout_width="match_parent"
        android:layout_height="wrap_content"
        android:orientation="vertical">

        <!-- Много контента -->

    </LinearLayout>
</ScrollView>
```

- **ScrollView** — может содержать только **один** дочерний элемент
- **NestedScrollView** — поддерживает вложенную прокрутку (для CoordinatorLayout)
- Для горизонтальной прокрутки — **HorizontalScrollView**

## Сравнение контейнеров

| Контейнер | Назначение | Производительность |
|-----------|-----------|-------------------|
| LinearLayout | Простая линейная компоновка | Высокая |
| RelativeLayout | Позиционирование относительно друг друга | Средняя |
| ConstraintLayout | Сложные макеты, плоская иерархия | Высокая (рекомендуемый) |
| FrameLayout | Наложение элементов, контейнер для Fragment | Высокая |
| ScrollView | Прокрутка | - |

## Важные моменты

- `ConstraintLayout` — **рекомендуемый** контейнер, заменяет большинство вложенных LinearLayout
- В `LinearLayout` используйте `weight` для пропорционального распределения (при `layout_width="0dp"`)
- `FrameLayout` — для наложения элементов и контейнера Fragment
- `ScrollView` — только один дочерний элемент
- `layout_gravity` — позиция элемента в родителе, `gravity` — позиция содержимого внутри элемента
