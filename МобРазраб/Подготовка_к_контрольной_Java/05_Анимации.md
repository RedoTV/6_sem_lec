# Java/XML: Анимации

## Типы анимаций в Android

1. **Property Animation** (ObjectAnimator, ValueAnimator) — изменение свойств View
2. **View Animation** (Tween-анимации) — устаревший, но простой API
3. **Drawable Animation** (AnimationDrawable) — покадровая анимация
4. **Layout Animation** — анимация появления элементов в Layout
5. **Transition Framework** — анимация переходов между сценами/Activity

---

## 1. Property Animation (рекомендуемый)

### ObjectAnimator — анимация свойства объекта

```java
// Плавное перемещение
ObjectAnimator moveX = ObjectAnimator.ofFloat(view, "translationX", 0f, 300f);
moveX.setDuration(1000);
moveX.start();

// Изменение прозрачности
ObjectAnimator fadeOut = ObjectAnimator.ofFloat(view, "alpha", 1f, 0f);
fadeOut.setDuration(500);
fadeOut.start();

// Изменение масштаба
ObjectAnimator scaleX = ObjectAnimator.ofFloat(view, "scaleX", 1f, 2f);
scaleX.setDuration(300);
scaleX.start();

// Вращение
ObjectAnimator rotate = ObjectAnimator.ofFloat(view, "rotation", 0f, 360f);
rotate.setDuration(1000);
rotate.start();

// Цвет фона
ObjectAnimator colorAnim = ObjectAnimator.ofArgb(view, "backgroundColor",
    Color.parseColor("#6200EE"), Color.parseColor("#03DAC5"));
colorAnim.setDuration(1000);
colorAnim.start();
```

### AnimatorSet — комбинация анимаций

```java
ObjectAnimator moveX = ObjectAnimator.ofFloat(view, "translationX", 0f, 200f);
ObjectAnimator moveY = ObjectAnimator.ofFloat(view, "translationY", 0f, 200f);
ObjectAnimator fadeOut = ObjectAnimator.ofFloat(view, "alpha", 1f, 0f);

AnimatorSet set = new AnimatorSet();
set.play(moveX).with(moveY);        // Одновременно
set.play(fadeOut).after(moveX);     // После завершения moveX
set.setDuration(500);
set.start();

// Или все одновременно
AnimatorSet together = new AnimatorSet();
together.playTogether(moveX, moveY, fadeOut);
together.start();

// Последовательно
AnimatorSet sequential = new AnimatorSet();
sequential.playSequentially(moveX, moveY, fadeOut);
sequential.start();
```

### ValueAnimator — полный контроль

```java
ValueAnimator animator = ValueAnimator.ofFloat(0f, 1f);
animator.setDuration(1000);
animator.addUpdateListener(animation -> {
    float value = (float) animation.getAnimatedValue();
    view.setAlpha(value);
    view.setScaleX(value);
    view.setScaleY(value);
});
animator.start();
```

### Слушатели анимации

```java
animator.addListener(new AnimatorListenerAdapter() {
    @Override
    public void onAnimationStart(Animator animation) {
        // Анимация началась
    }

    @Override
    public void onAnimationEnd(Animator animation) {
        // Анимация завершилась
        view.setVisibility(View.GONE);
    }

    @Override
    public void onAnimationCancel(Animator animation) {
        // Анимация отменена
    }
});
```

### Interpolators (интерполяторы)

```java
animator.setInterpolator(new AccelerateInterpolator());       // Ускорение
animator.setInterpolator(new DecelerateInterpolator());       // Замедление
animator.setInterpolator(new AccelerateDecelerateInterpolator()); // Ускорение + замедление
animator.setInterpolator(new LinearInterpolator());           // Равномерно
animator.setInterpolator(new AnticipateInterpolator());       // Откат назад, затем вперёд
animator.setInterpolator(new OvershootInterpolator());        // Перелёт, затем возврат
animator.setInterpolator(new BounceInterpolator());           // Пружина/отскок
animator.setInterpolator(new CycleInterpolator(2));           // Повтор (2 цикла)
```

### Repeat

```java
animator.setRepeatCount(ValueAnimator.INFINITE);  // Бесконечно
animator.setRepeatCount(3);                       // 3 раза
animator.setRepeatMode(ValueAnimator.RESTART);    // Сначала (по умолчанию)
animator.setRepeatMode(ValueAnimator.REVERSE);    // В обратном направлении
```

## 2. XML Property Animation

```xml
<!-- res/animator/scale_up.xml -->
<objectAnimator
    xmlns:android="http://schemas.android.com/apk/res/android"
    android:propertyName="scaleX"
    android:valueFrom="1"
    android:valueTo="1.5"
    android:duration="300"
    android:interpolator="@android:interpolator/accelerate_decelerate"
    android:repeatCount="1"
    android:repeatMode="reverse" />
```

```xml
<!-- res/animator/move_and_fade.xml -->
<set xmlns:android="http://schemas.android.com/apk/res/android"
    android:ordering="together">

    <objectAnimator
        android:propertyName="translationX"
        android:valueFrom="0"
        android:valueTo="200"
        android:duration="500" />

    <objectAnimator
        android:propertyName="alpha"
        android:valueFrom="1"
        android:valueTo="0"
        android:duration="500"
        android:startOffset="250" />

</set>
```

Загрузка и запуск:
```java
Animator animator = AnimatorInflater.loadAnimator(this, R.animator.scale_up);
animator.setTarget(view);
animator.start();
```

## 3. View Animation (Tween-анимация) — устаревший API

```xml
<!-- res/anim/fade_in.xml -->
<alpha xmlns:android="http://schemas.android.com/apk/res/android"
    android:fromAlpha="0.0"
    android:toAlpha="1.0"
    android:duration="500"
    android:interpolator="@android:anim/accelerate_interpolator" />
```

```xml
<!-- res/anim/slide_in_right.xml -->
<set xmlns:android="http://schemas.android.com/apk/res/android"
    android:shareInterpolator="false">

    <translate
        android:fromXDelta="100%"
        android:toXDelta="0%"
        android:duration="300"
        android:interpolator="@android:anim/decelerate_interpolator" />

    <alpha
        android:fromAlpha="0.0"
        android:toAlpha="1.0"
        android:duration="300" />

</set>
```

```xml
<!-- res/anim/rotate.xml -->
<rotate xmlns:android="http://schemas.android.com/apk/res/android"
    android:fromDegrees="0"
    android:toDegrees="360"
    android:pivotX="50%"
    android:pivotY="50%"
    android:duration="1000"
    android:repeatCount="infinite" />
```

```xml
<!-- res/anim/scale.xml -->
<scale xmlns:android="http://schemas.android.com/apk/res/android"
    android:fromXScale="1.0"
    android:toXScale="1.5"
    android:fromYScale="1.0"
    android:toYScale="1.5"
    android:pivotX="50%"
    android:pivotY="50%"
    android:duration="300"
    android:repeatMode="reverse"
    android:repeatCount="1" />
```

Загрузка и запуск:
```java
Animation fadeIn = AnimationUtils.loadAnimation(this, R.anim.fade_in);
view.startAnimation(fadeIn);

Animation slideIn = AnimationUtils.loadAnimation(this, R.anim.slide_in_right);
view.startAnimation(slideIn);
```

Слушатель:
```java
animation.setAnimationListener(new Animation.AnimationListener() {
    @Override
    public void onAnimationStart(Animation animation) {}

    @Override
    public void onAnimationEnd(Animation animation) {
        view.setVisibility(View.GONE);
    }

    @Override
    public void onAnimationRepeat(Animation animation) {}
});
```

## 4. Layout Animation — анимация появления элементов

```xml
<!-- res/anim/layout_fade_in.xml -->
<alpha xmlns:android="http://schemas.android.com/apk/res/android"
    android:fromAlpha="0.0"
    android:toAlpha="1.0"
    android:duration="300" />
```

```xml
<!-- res/anim/layout_animation.xml -->
<layoutAnimation xmlns:android="http://schemas.android.com/apk/res/android"
    android:animation="@anim/layout_fade_in"
    android:delay="0.3"
    android:animationOrder="normal" />
```

Применение к ViewGroup:
```xml
<RecyclerView
    android:layoutAnimation="@anim/layout_animation"
    ... />
```

Из кода:
```java
LayoutAnimationController controller = AnimationUtils.loadLayoutAnimation(this, R.anim.layout_animation);
recyclerView.setLayoutAnimation(controller);
recyclerView.getAdapter().notifyDataSetChanged();
recyclerView.scheduleLayoutAnimation();
```

## 5. Transition Framework

### Activity Transition

```java
// В стилях (themes.xml)
<item name="android:windowActivityTransitions">true</item>

// Activity A — запуск
Intent intent = new Intent(this, DetailActivity.class);
ActivityOptions options = ActivityOptions.makeSceneTransitionAnimation(
    this,
    imageView, "profile_image"    // shared element
);
startActivity(intent, options.toBundle());

// В Activity B — XML
<ImageView
    android:transitionName="profile_image"
    ... />
```

### Scene Transition

```java
Scene scene1 = Scene.getSceneForLayout(sceneRoot, R.layout.scene1, this);
Scene scene2 = Scene.getSceneForLayout(sceneRoot, R.layout.scene2, this);

Transition transition = new Fade();
// Transition transition = new ChangeBounds();
// Transition transition = new Slide(Gravity.RIGHT);

TransitionManager.go(scene2, transition);
```

### Auto Transition (автоматическая)

```java
TransitionManager.beginDelayedTransition(parentLayout);
// Изменяем layout программно
view.setLayoutParams(new LayoutParams(...));
// Анимация применится автоматически
```

## 6. Покадровая анимация (AnimationDrawable)

```xml
<!-- res/drawable/animation_list.xml -->
<animation-list xmlns:android="http://schemas.android.com/apk/res/android"
    android:oneshot="false">

    <item android:drawable="@drawable/frame1" android:duration="100" />
    <item android:drawable="@drawable/frame2" android:duration="100" />
    <item android:drawable="@drawable/frame3" android:duration="100" />
    <item android:drawable="@drawable/frame4" android:duration="100" />

</animation-list>
```

```xml
<ImageView
    android:id="@+id/animationView"
    android:src="@drawable/animation_list" />
```

```java
ImageView animView = findViewById(R.id.animationView);
AnimationDrawable frameAnimation = (AnimationDrawable) animView.getDrawable();
frameAnimation.start();
// frameAnimation.stop();
```

## ViewPropertyAnimator — удобный API

```java
view.animate()
    .translationX(200f)
    .translationY(100f)
    .alpha(0.5f)
    .scaleX(1.5f)
    .scaleY(1.5f)
    .rotation(45f)
    .setDuration(500)
    .setInterpolator(new AccelerateDecelerateInterpolator())
    .withStartAction(() -> { /* до начала */ })
    .withEndAction(() -> { /* после завершения */ })
    .start();
```

## Важные моменты

- **Property Animation** (`ObjectAnimator`) — основной рекомендуемый API
- **View Animation** (`AnimationUtils`) — устаревший, но простой; не меняет реальные координаты View
- **AnimatorSet** — для комбинирования нескольких анимаций
- **Interpolators** — управление "характером" анимации (ускорение, отскок и т.д.)
- **ViewPropertyAnimator** — самый короткий способ (`view.animate().alpha(0f)`)
- XML-анимации хранятся в `res/animator/` (Property) или `res/anim/` (View Animation)
- `startOffset` в XML — задержка перед началом анимации
