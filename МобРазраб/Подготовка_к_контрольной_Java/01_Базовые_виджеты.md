# Java/XML: Базовые виджеты (TextView, EditText, Button, ImageView)

## TextView

Отображение текста.

```xml
<TextView
    android:id="@+id/textView"
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:text="Привет, мир!"
    android:textSize="18sp"
    android:textColor="#FF0000"
    android:textStyle="bold|italic"
    android:fontFamily="serif"
    android:letterSpacing="0.1"
    android:lineSpacingExtra="4dp"
    android:maxLines="2"
    android:ellipsize="end"
    android:gravity="center"
    android:textAlignment="center"
    android:background="#EEEEEE"
    android:padding="8dp" />
```

Из кода:
```java
TextView textView = findViewById(R.id.textView);
textView.setText("Новый текст");
textView.setTextColor(Color.RED);
textView.setTextSize(20);
textView.setTypeface(Typeface.DEFAULT_BOLD);
textView.setMaxLines(3);
```

## EditText

Поле ввода текста.

```xml
<EditText
    android:id="@+id/editText"
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:hint="Введите имя"
    android:inputType="text"
    android:singleLine="true"
    android:maxLines="1"
    android:maxLength="50"
    android:textColorHint="#AAAAAA"
    android:backgroundTint="#6200EE" />
```

Типы ввода (`android:inputType`):
- `text` — обычный текст
- `textEmailAddress` — email
- `textPassword` — пароль (скрытые символы)
- `number` — числа
- `phone` — телефон
- `textMultiLine` — многострочный
- `textUri` — URL

Из кода:
```java
EditText editText = findViewById(R.id.editText);
String text = editText.getText().toString();
editText.setText("Значение");

// Очистка
editText.setText("");
```

## Button

Кнопка.

```xml
<Button
    android:id="@+id/button"
    android:layout_width="match_parent"
    android:layout_height="wrap_content"
    android:text="Нажми меня"
    android:textColor="#FFFFFF"
    android:backgroundTint="#6200EE"
    android:textAllCaps="false"
    android:enabled="true"
    android:drawableStart="@drawable/ic_icon"
    android:drawablePadding="8dp" />
```

Из кода:
```java
Button button = findViewById(R.id.button);
button.setText("Новый текст");
button.setEnabled(false);
button.setOnClickListener(v -> {
    // Действие при клике
    String input = editText.getText().toString();
    textView.setText("Вы ввели: " + input);
});
```

Варианты кнопок:
```xml
<!-- Обычная кнопка -->
<Button ... />

<!-- Кнопка без фона (только текст) -->
<Button
    style="@style/Widget.AppCompat.Button.Borderless"
    ... />

<!-- Кнопка с обводкой -->
<Button
    style="@style/Widget.AppCompat.Button.Borderless.Colored"
    ... />
```

## ImageView

Отображение изображений.

```xml
<ImageView
    android:id="@+id/imageView"
    android:layout_width="200dp"
    android:layout_height="200dp"
    android:src="@drawable/my_image"
    android:scaleType="centerCrop"
    android:contentDescription="Описание изображения"
    android:adjustViewBounds="true"
    android:background="#EEEEEE" />
```

ScaleType:
- `center` — по центру без масштабирования
- `centerCrop` — заполнить с обрезкой (самый частый)
- `centerInside` — вписать целиком
- `fitCenter` — вписать с сохранением пропорций
- `fitXY` — растянуть на весь View
- `matrix` — ручная матрица трансформации

Из кода:
```java
ImageView imageView = findViewById(R.id.imageView);

// Из ресурсов
imageView.setImageResource(R.drawable.another_image);

// Из drawable
imageView.setImageDrawable(ContextCompat.getDrawable(this, R.drawable.my_image));

// Круглое изображение (нужна библиотека Glide/Coil или Bitmap)
// Или через ShapeableImageView (Material Components)
```

### Круглое изображение (ClipOval программно)

```java
// Android 5.0+ через Outline
imageView.setClipToOutline(true);
imageView.setOutlineProvider(new ViewOutlineProvider() {
    @Override
    public void getOutline(View view, Outline outline) {
        outline.setOval(0, 0, view.getWidth(), view.getHeight());
    }
});
```

## Скруглённые углы ImageView

```xml
<!-- Через ShapeableImageView (Material Components) -->
<com.google.android.material.imageview.ShapeableImageView
    android:id="@+id/roundedImage"
    android:layout_width="100dp"
    android:layout_height="100dp"
    android:src="@drawable/my_image"
    android:scaleType="centerCrop"
    app:shapeAppearanceOverlay="@style/RoundedImage" />
```

```xml
<!-- styles.xml -->
<style name="RoundedImage">
    <item name="cornerFamily">rounded</item>
    <item name="cornerSize">16dp</item>
</style>

<!-- Круг -->
<style name="CircleImage">
    <item name="cornerFamily">rounded</item>
    <item name="cornerSize">50%</item>
</style>
```

## Важные моменты

- `wrap_content` — размер по содержимому
- `match_parent` — заполнить родителя
- `sp` — для шрифтов, `dp` — для размеров элементов
- `android:id="@+id/name"` — установка ID для доступа из кода
- `findViewById()` — получение ссылки на View (или `ViewBinding`)
- Все строковые ресурсы выносить в `strings.xml`: `android:text="@string/hello"`
