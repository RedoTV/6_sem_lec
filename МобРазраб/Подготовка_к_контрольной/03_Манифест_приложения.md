# Манифест приложения (AndroidManifest.xml)

AndroidManifest.xml — обязательный файл конфигурации, расположенный в `app/src/main/AndroidManifest.xml`. Он сообщает системе Android о компонентах приложения, разрешениях и настройках.

## Структура манифеста

```xml
<?xml version="1.0" encoding="utf-8"?>
<manifest xmlns:android="http://schemas.android.com/apk/res/android"
    package="com.example.myapp">

    <!-- Разрешения -->
    <uses-permission android:name="android.permission.INTERNET" />
    <uses-permission android:name="android.permission.CAMERA" />
    <uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />

    <!-- Характеристики устройства -->
    <uses-feature android:name="android.hardware.camera" android:required="true" />

    <application
        android:name=".MyApplication"
        android:allowBackup="true"
        android:icon="@mipmap/ic_launcher"
        android:label="@string/app_name"
        android:roundIcon="@mipmap/ic_launcher_round"
        android:supportsRtl="true"
        android:theme="@style/Theme.MyApp">

        <!-- Activity -->
        <activity
            android:name=".MainActivity"
            android:exported="true">
            <intent-filter>
                <action android:name="android.intent.action.MAIN" />
                <category android:name="android.intent.category.LAUNCHER" />
            </intent-filter>
        </activity>

        <!-- Service -->
        <service
            android:name=".MyService"
            android:exported="false" />

        <!-- BroadcastReceiver -->
        <receiver
            android:name=".MyReceiver"
            android:exported="false" />

        <!-- ContentProvider -->
        <provider
            android:name=".MyProvider"
            android:authorities="com.example.myapp.provider"
            android:exported="false" />

    </application>
</manifest>
```

## Основные элементы

### `<manifest>`
Корневой элемент. Содержит атрибут `package` — уникальный идентификатор приложения.

### `<application>`
Настройки приложения:
- `android:name` — класс Application (если есть)
- `android:icon` — иконка приложения
- `android:label` — название приложения
- `android:theme` — тема приложения
- `android:allowBackup` — резервное копирование

### `<activity>`
Регистрация Activity:
- `android:name` — класс Activity (обязательно)
- `android:exported` — доступность для других приложений (`true` для launcher-activity)
- `android:screenOrientation` — ориентация экрана
- `android:configChanges` — самостоятельная обработка изменений конфигурации

### `<intent-filter>` внутри `<activity>`
Определяет, как Activity реагирует на Intent'ы:
```xml
<intent-filter>
    <action android:name="android.intent.action.MAIN" />
    <category android:name="android.intent.category.LAUNCHER" />
</intent-filter>
```
Это делает Activity точкой входа (иконка в лаунчере).

### `<uses-permission>`
Запрос разрешений:
```xml
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" />
<uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE" />
```

### `<uses-feature>`
Объявление использования аппаратных/программных функций:
```xml
<uses-feature android:name="android.hardware.camera" android:required="false" />
```
`android:required="false"` — приложение работает и без этой функции.

## android:exported

Начиная с Android 12 (API 31) **обязательно** указывать `android:exported` для всех компонентов:
- `true` — компонент доступен другим приложениям
- `false` — компонент приватный, только для данного приложения
- Должен быть `true`, если компонент имеет `<intent-filter>`

## Важные моменты

- Каждый Activity, Service, BroadcastReceiver, ContentProvider **обязан** быть зарегистрирован в манифесте
- `package` в манифесте используется как base package для всех компонентов
- Разрешения (permissions) делятся на:
  - **Обычные** (install-time) — автоматически предоставляются при установке
  - **Опасные** (runtime) — требуют запрос у пользователя во время работы (`CAMERA`, `LOCATION`, `STORAGE`)
- `android:exported="true"` с `<intent-filter>` означает, что любое приложение может запустить эту Activity
