# Ресурсы приложения (строки, цвета, размеры, темы)

Ресурсы в Android выносятся из кода в отдельные файлы. Это позволяет:
- Локализовать приложение (перевод на разные языки)
- Адаптировать UI под разные экраны и плотности
- Изменять дизайн без перекомпиляции кода

Все ресурсы хранятся в `app/src/main/res/`.

## Структура папок ресурсов

```
res/
├── values/
│   ├── strings.xml      — строковые ресурсы
│   ├── colors.xml       — цвета
│   ├── dimens.xml       — размеры
│   ├── themes.xml       — темы
│   └── styles.xml       — стили
├── drawable/            — изображения, векторные drawable, shapes
├── mipmap-*/            — иконки приложения (разные плотности)
├── layout/              — XML-макеты (не используются в Compose)
├── font/                — шрифты
├── raw/                 — сырые файлы (аудио, видео)
└── xml/                 — произвольные XML-файлы
```

## Строковые ресурсы (strings.xml)

```xml
<!-- res/values/strings.xml -->
<resources>
    <string name="app_name">Моё приложение</string>
    <string name="welcome_message">Привет, %1$s!</string>
    <string name="cart_count">В корзине: %1$d товаров</string>
    <string name="long_text">Очень длинный текст...</string>

    <string-array name="planets">
        <item>Меркурий</item>
        <item>Венера</item>
        <item>Земля</item>
    </string-array>

    <plurals name="items_count">
        <item quantity="one">%d товар</item>
        <item quantity="few">%d товара</item>
        <item quantity="many">%d товаров</item>
    </plurals>
</resources>
```

Использование в коде:
```kotlin
val appName = getString(R.string.app_name)
val formatted = getString(R.string.welcome_message, "Иван")
val planets = resources.getStringArray(R.array.planets)
val quantity = resources.getQuantityString(R.plurals.items_count, count, count)
```

Использование в Compose:
```kotlin
Text(text = stringResource(R.string.app_name))
Text(text = stringResource(R.string.welcome_message, "Иван"))
```

## Цвета (colors.xml)

```xml
<!-- res/values/colors.xml -->
<resources>
    <color name="purple_200">#FFBB86FC</color>
    <color name="purple_500">#FF6200EE</color>
    <color name="purple_700">#FF3700B3</color>
    <color name="teal_200">#FF03DAC5</color>
    <color name="black">#FF000000</color>
    <color name="white">#FFFFFFFF</color>
</resources>
```

Использование в Compose:
```kotlin
val purple500 = colorResource(R.color.purple_500)
// Или лучше — определить в Color.kt:
val Purple500 = Color(0xFF6200EE)
```

## Размеры (dimens.xml)

```xml
<!-- res/values/dimens.xml -->
<resources>
    <dimen name="padding_small">8dp</dimen>
    <dimen name="padding_medium">16dp</dimen>
    <dimen name="padding_large">24dp</dimen>
    <dimen name="text_size_title">24sp</dimen>
    <dimen name="text_size_body">16sp</dimen>
    <dimen name="corner_radius">12dp</dimen>
</resources>
```

Единицы измерения:
- **dp** (density-independent pixels) — для размеров UI-элементов
- **sp** (scale-independent pixels) — для размеров шрифтов (учитывает настройки масштабирования пользователя)
- **px** — физические пиксели (избегать)

Использование в Compose:
```kotlin
val paddingMedium = dimensionResource(R.dimen.padding_medium)
// Или напрямую в коде:
Modifier.padding(16.dp)
```

## Темы (themes.xml)

```xml
<!-- res/values/themes.xml -->
<resources>
    <style name="Theme.MyApp" parent="Theme.MaterialComponents.DayNight.DarkActionBar">
        <item name="colorPrimary">@color/purple_500</item>
        <item name="colorPrimaryVariant">@color/purple_700</item>
        <item name="colorOnPrimary">@color/white</item>
        <item name="colorSecondary">@color/teal_200</item>
        <item name="android:statusBarColor">@color/purple_700</item>
    </style>
</resources>
```

### Тема в Jetpack Compose

```kotlin
// Color.kt
val Purple200 = Color(0xFFBB86FC)
val Purple500 = Color(0xFF6200EE)
val Purple700 = Color(0xFF3700B3)
val Teal200 = Color(0FF03DAC5)

// Theme.kt
private val LightColorScheme = lightColorScheme(
    primary = Purple500,
    secondary = Teal200,
    background = Color(0xFFFFFBFE),
    surface = Color(0xFFFFFBFE),
    onPrimary = Color.White,
    onSecondary = Color.Black,
    onBackground = Color.Black,
    onSurface = Color.Black,
)

private val DarkColorScheme = darkColorScheme(
    primary = Purple200,
    secondary = Teal200,
    background = Color(0xFF1C1B1F),
    surface = Color(0xFF1C1B1F),
    onPrimary = Color.Black,
    onSecondary = Color.Black,
    onBackground = Color.White,
    onSurface = Color.White,
)

@Composable
fun MyAppTheme(
    darkTheme: Boolean = isSystemInDarkTheme(),
    content: @Composable () -> Unit
) {
    val colorScheme = if (darkTheme) DarkColorScheme else LightColorScheme

    MaterialTheme(
        colorScheme = colorScheme,
        typography = Typography,
        shapes = Shapes,
        content = content
    )
}
```

Использование:
```kotlin
MyAppTheme {
    Surface(
        modifier = Modifier.fillMaxSize(),
        color = MaterialTheme.colorScheme.background
    ) {
        Text(
            text = "Hello",
            color = MaterialTheme.colorScheme.primary
        )
    }
}
```

## Типографика (Typography)

```kotlin
val Typography = Typography(
    displayLarge = TextStyle(fontSize = 57.sp, fontWeight = FontWeight.Normal),
    headlineLarge = TextStyle(fontSize = 32.sp, fontWeight = FontWeight.Normal),
    titleLarge = TextStyle(fontSize = 22.sp, fontWeight = FontWeight.Normal),
    bodyLarge = TextStyle(fontSize = 16.sp, fontWeight = FontWeight.Normal),
    bodyMedium = TextStyle(fontSize = 14.sp, fontWeight = FontWeight.Normal),
    labelLarge = TextStyle(fontSize = 14.sp, fontWeight = FontWeight.Medium),
    labelSmall = TextStyle(fontSize = 11.sp, fontWeight = FontWeight.Medium),
)
```

## Важные моменты

- Ресурсы обращаются через `R.класс.имя` (например, `R.string.app_name`)
- Для разных языков — папки `values-ru/`, `values-en/`, `values-fr/`
- Для разных плотностей экрана — `drawable-mdpi/`, `drawable-hdpi/`, `drawable-xhdpi/`
- Для ночной темы — `values-night/`
- В Compose предпочтительнее определять цвета/типографику прямо в Kotlin-коде (Theme.kt, Color.kt, Type.kt)
